# The Lost Shell — Browser VR Game

Een kleine 3D-avonturengame in A-Frame die in de browser werkt en VR ondersteunt.

## Bestanden
- `index.html` — de scene, wereld, camera, HUD en overlays
- `style.css` — de interface en responsive styling
- `game.js` — missies, verzamelen, interacties, energie en herstarten

## Starten
1. Pak `the_lost_shell_vr.zip` uit.
2. Open de map in Visual Studio Code.
3. Start `index.html` met Live Server, of gebruik een andere lokale webserver.
4. Klik op **Start avontuur**.

Je kunt de HTML ook rechtstreeks openen voor desktoptesten, maar een lokale server is betrouwbaarder voor VR en browserfuncties.

## Besturing
- Desktop: WASD of pijltjestoetsen bewegen; muis om rond te kijken.
- Interactie: richt met de cursor op een interactief object en klik. Je kunt ook `E` gebruiken als je dicht genoeg bij een object staat.
- VR: druk op **Enter VR**, gebruik een compatibele controller en druk op de trigger.

## Doel
1. Vind de drie turquoise schelpen.
2. Ontdek de verborgen grot.
3. Activeer het oude altaar.
4. Keer terug naar de boot.

Paarse kristallen kosten energie als je te dichtbij komt.

## Let op
A-Frame wordt geladen via een CDN, dus internet is nodig. VR vereist een compatibele browser/headset en doorgaans HTTPS of localhost.
